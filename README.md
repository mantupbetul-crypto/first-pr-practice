# first-pr-practice

My first repo, set up to practice opening a pull request with Claude Code.

## About

This repository is a sandbox for learning the GitHub pull request workflow:
branch, commit, push, and open a PR for review.

## Getting Started

1. Clone the repo.
2. Make a change on a new branch.
3. Open a pull request and merge it once it looks good.

This is a great way to practice contributing to a project before you recieve
your first real code review.
